## Reproducing the video

1. Follow this repository's `EXPERIMENT_SETUP.md` to clone Spring PetClinic REST at the pinned baseline and create a fresh working branch.
2. Use the **official installation guide** above to install the Spec Kit CLI; installation instructions can change across releases.
3. Review the **existing-project guide** before initializing Spec Kit in the cloned PetClinic repository.
4. Follow the experiment in the video and examine its committed specifications, plans, tasks, and implementation as applicable.

> **Note:** This document links to the current official documentation. It does not guarantee that today's Spec Kit release or commands exactly match the version used when the video was recorded.

Spec Kit is maintained by its own contributors. This repository is an independent learning experiment, not an official Spec Kit example or endorsement.
